# أنت المهندس — المحرك التجريبي

نسخة بحثية عامة لفحص توليد مخططات الفلل وتنسيق الدورين. تاريخ اللقطة: 15 نوفمبر 2026.

هذه نسخة مستقلة من ملفات التجارب المحلية، وليست الموقع الإنتاجي ولا الفرع المؤرشف الموقوف.

البدائل الثلاثة على أرض 22×40م، بنفس البرنامج: غرفتا نوم أرضيتان، وثلاث غرف أولاد وجناح رئيسي في الأول. اجتياز الفحوص المحددة لا يمثل اعتمادًا معماريًا أو إنشائيًا أو امتثالًا للاشتراطات المحلية.

المحاولات المرفوضة محفوظة أيضًا لتسهيل التحليل. توجد سكربتات بحثية قديمة تستخدم مسارات بيئة العمل الأصلية؛ راجع الدليل قبل تشغيلها. لم تُعدّل مصادر المحرك عند إعداد هذه اللقطة.

## تنزيل الملفات

استخدم **Code → Download ZIP** لتنزيل المستودع كاملًا دون تسجيل دخول.

التبعيات مثبتة الإصدارات في package.json وrequirements.txt؛ المكتبات المثبتة والبيئة الافتراضية وبيانات الدخول غير مضمّنة.
