# ملفات محرك أنت المهندس التجريبي للفحص البرمجي

هذه لقطة من الملفات المحلية بتاريخ 2026-11-15، وليست مستودع Git منشورًا، ولا تتضمن سجل Git أو الموقع الإنتاجي. الكود الموجود نُسخ دون تعديل؛ أضيف هذا الدليل وملفات الحصر ومتطلبات التثبيت فقط.

## نقطة البداية للمحلل

- `latest_narrow_engine/`: أحدث نسخة بحثية، بما فيها المحاولات المرفوضة وأسباب رفضها.
- `latest_narrow_engine/SELECTED.json`: يربط البدائل النهائية A وB وC بمجلدات trial_b وF وC2.
- `latest_narrow_engine/VERIFIED.json`: نتائج التحقق المسجلة للبدائل الثلاثة على أرض 22×40م.
- داخل كل حالة: REQUEST.json ثم GROUND_RAW.json ثم GROUND.json وGROUND_audit.json وGROUND_PROVENANCE.json، ثم SOLVER.json وCOORDINATION.json وVILLA.arch وCOMPILER_FACTS.json وACCEPTANCE.json. ليست جميع الملفات موجودة في المحاولات الفاشلة.
- `previous_ground_program_engine/`: النسخة السابقة واختبارات اختلاف برامج العملاء على نفس الأرض.
- `site_shape_benchmark/`: اختبار أشكال الأراضي الذي كشف تعثر الأرض الضيقة.

## مسار التنفيذ الأساسي

pipeline.py → run.prepare_ground → ground_solver/complete/wall_pockets/audit/privacy/stair/floorplate → upper_solver → coordinate → emit → ArchLang → contract.

لإعادة تجربة مدخل محدد، من داخل latest_narrow_engine، بعد تثبيت Python 3.12 وNode.js والمكتبات:

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
npm install
.venv/bin/python pipeline.py --request F/REQUEST.json --out replay_F --seconds 45 --no-render
```

الوضع --no-render ينتج بيانات التحقق وملفات ArchLang دون PDF أو DXF أو صور. لتصدير الصور فقط بعد نجاح المحاولة:

```sh
node render_png.mjs replay_F
```

هذه تعليمات تشغيل ولم يُنفذ تثبيت جديد أو تشغيل شامل من الحزمة المعزولة. حدود الوقت وتعدد عمال البحث قد يغيران الحل أو ينتجان UNKNOWN. التلميحات محفوظة في المدخلات وهي غير مقفلة، ولا تضمن إعادة الحل نفسه.

## حدود ينبغي أن يراها المحلل

- هذه تجربة محدودة، وليست محركًا عامًا لكل الفلل أو اشتراطات السعودية واليمن.
- ما زالت هناك أدوار تنظيمية وأسماء غرف مفترضة، وشارع جنوبي ووصول شمالي للسلم.
- بعض سكربتات البحث والمقارنة القديمة تعتمد مسارات /workspace أو مجلدات من الجلسة الأصلية. لا تعتبر كل سكربت نقطة تشغيل مستقلة؛ افحصها قبل تشغيلها. ملفاتها الأصلية محفوظة لتكون المراجعة أمينة.
- تحويل الرسم يتضمن مرجعًا رأسيًا ثابتًا 35000، وبعض أدوات المساعدة الموروثة تحتاج تنظيفًا؛ المطلوب من التحليل تقييم ذلك، لا افتراض جاهزية الإنتاج.
- الخصوصية تعتمد عينات خطوط رؤية محدودة، والنوافذ الخارجية لا تثبت أداء الإنارة والتهوية.
- الأعمدة ومجاري الخدمات حجوزات مكانية أولية؛ لا يوجد اعتماد لقدرات العناصر أو التربة أو التسليح أو منظومة دعم السقف.
- تظهر تحذيرات متعمدة أو معلنة عن غياب التجهيزات والتوجيه الشمسي، وفي C تحذير تداخل تسمية. التأثيث معلق، وتسميات الرسم إنجليزية دون أبعاد مكتوبة.
- لم تُضمّن node_modules أو البيئة الافتراضية أو كلمات المرور أو مفاتيح الدخول. لم تُضمّن PDF أو DXF أو ملفات الصور المتكررة؛ أُبقيت صور الدورين للبدائل النهائية فقط.

## مقترح طلب للمحلل

افحص صحة نموذج القيود، واستقلال فحوص القبول، وصحة المساحات والفتحات والحركة والخصوصية، والتوافق بين الدورين، وحدود التنسيق الإنشائي، وقابلية التشغيل خارج بيئة الجلسة. صنف النتائج إلى عيوب مؤكدة ومخاطر تحتاج اختبارًا، واذكر مسارات الملفات والأسطر، واقترح إصلاحات مرتبة بالأولوية مع اختبارات قبول. لا تعتبر نجاح الحالات الثلاث دليلًا على دعم جميع برامج العملاء.

MANIFEST.json يحصر الملفات وبصمة SHA-256 لكل ملف. PACKAGE_CHECKS.json يسجل فحوص الحزمة فقط؛ فحص تركيب Python ليس اختبار تشغيل للمحرك.
